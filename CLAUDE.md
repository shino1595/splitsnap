# SplitSnap project rules

- **No costs beyond the user's Claude subscription.** Do not use, sign up for, or recommend anything that is billed separately or needs payment. That includes paid APIs (such as Claude API or vision), paid OCR or cloud tiers, paid Expo/EAS plans, app-store developer fees, and Claude extra usage. Free tiers are fine (OCR.space free key or demo key, Expo Snack, Expo Go, jsDelivr), but state their limits. If something would cost money, stop and ask the user first; expect the answer to be no.
- **No installs on this PC.** No Node.js, npm, Python or other software. JavaScript and TypeScript run only in headless Microsoft Edge through `tools\*.ps1`.
- The module contract is `docs\ARCHITECTURE.md`.
